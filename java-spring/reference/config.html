Cheat sheet · từ Bài 5

Đọc giá trị

# application.properties
shop.name=Son Shop
shop.hotline=1900-1234

// Một giá trị
public OrderService(@Value("${shop.name}") String shopName) { ... }
@Value("${shop.name:Mặc định}")        // có giá trị dự phòng

// Một nhóm giá trị (khuyên dùng)
@ConfigurationProperties(prefix = "shop")
public record ShopProperties(String name, String hotline) {}

@SpringBootApplication
@ConfigurationPropertiesScan           // bắt buộc, nếu không sẽ không có bean ShopProperties

Thứ tự ghi đè (rút gọn, yếu → mạnh)

  1. application.properties
  2. application-{profile}.properties
  3. Biến môi trường: SHOP_NAME=...
  4. Tham số dòng lệnh: --shop.name=...

Lệnh hay dùng

mvn spring-boot:run -Dspring-boot.run.arguments=--shop.name=TestShop
mvn spring-boot:run -Dspring-boot.run.arguments=--spring.profiles.active=dev
java -jar app.jar --server.port=9090
SHOP_NAME=Prod java -jar app.jar
