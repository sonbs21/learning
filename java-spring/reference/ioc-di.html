IoC, DI & Bean

Cheat sheet · từ Bài 1

Thuật ngữ

TừNghĩa
DependencyObject mà một class cần dùng để làm việc (OrderService cần EmailSender).
DI (Dependency Injection)Đưa dependency vào cho object, thường là qua constructor, thay vì để object tự new.
IoC (Inversion of Control)Quyền tạo và lắp ráp object chuyển từ class sang container. DI là một dạng của IoC.
Container / ApplicationContextObject của Spring chuyên tạo, lắp ráp và giữ các bean.
BeanObject do container tạo, lắp ráp và quản lý.
@ComponentĐánh dấu "Spring hãy tạo bean từ class này".

Mẫu code chuẩn

@Component
public class OrderService {
    private final EmailSender emailSender;          // phụ thuộc vào interface

    public OrderService(EmailSender emailSender) {  // constructor injection
        this.emailSender = emailSender;              // chỉ 1 constructor ⇒ không cần @Autowired
    }
}

// Xin bean từ container
ApplicationContext context = SpringApplication.run(App.class, args);
OrderService s = context.getBean(OrderService.class);

@Component hay @Bean Bài 3

@Configuration
public class AppConfig {
    @Bean                                   // tên bean = tên method: "clock"
    public Clock clock() { return Clock.systemDefaultZone(); }
}
  • @Component (cùng @Service, @Repository, @Controller): dùng cho class do bạn viết.
  • @Bean: dùng cho class của thư viện, hoặc khi cách tạo object cần logic.

Scope & vòng đời Bài 4

ScopeSố object@PreDestroy
singleton (mặc định)1, tạo lúc app khởi động, mọi nơi dùng chungCó, gọi khi container đóng
@Scope("prototype")Mỗi lần xin bean là một object mớiKhông được gọi

Thứ tự: constructor → @PostConstruct → dùng → @PreDestroy. Không lưu dữ liệu riêng của từng người dùng vào field của bean singleton.

Ghi nhớ

  • Tên bean mặc định là tên class với chữ cái đầu viết thường: ConsoleEmailSender → consoleEmailSender.
  • Spring quét package chứa class @SpringBootApplication và các package con.
  • "JavaBean" (class có getter/setter) không phải là "Spring bean".
