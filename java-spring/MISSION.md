# Mission: Spring Boot từ con số 0 đến Backend Java Engineer

## Why
Trở thành backend Java engineer hiểu Spring Boot đến tận bản chất: xây được API thật, debug được lỗi khó trong công việc, và trả lời được phỏng vấn kiểu "nó hoạt động thế nào / tại sao", thay vì code theo kiểu "chạy được là xong".

## Success looks like
- Tự giải thích và chứng minh bằng code: IoC/DI, bean, ApplicationContext, auto-configuration.
- Tự xây một REST API Spring Boot hoàn chỉnh: controller, validation, xử lý lỗi, database (JPA), security, test.
- Hiểu proxy và biết vì sao `@Transactional`, `@Async`, `@Cacheable` có lúc "không chạy".
- Nhìn lỗi JPA (N+1, LazyInitializationException) là biết nguyên nhân và cách sửa.
- Trả lời được các câu hỏi phỏng vấn Spring Boot từ cơ bản đến nâng cao.

## Constraints
- Học như người mới: dạy lại từ đầu, không giả định kiến thức Spring có sẵn, không dựa vào notes cũ.
- Giả định đã biết Java cơ bản (class, interface, constructor).
- Mỗi buổi 30–60 phút, học bằng code thật + quiz trên project `./lab/`.
- Môi trường: Java 21, Maven, Spring Boot 3.5.x.

## Out of scope (hiện tại)
- Spring WebFlux / reactive.
- Spring Cloud, Kubernetes, microservices.
- Kotlin, Gradle.
