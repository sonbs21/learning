Quy tắc: == cho primitive, enum, null. equals / Objects.equals cho mọi trường hợp so sánh nội dung.

Hợp đồng

a.equals(b) ⇒ a.hashCode() == b.hashCode() (bắt buộc).
Chiều ngược lại không đúng: collision là hợp lệ ("Aa", "BB" → 2112).
Override equals thì phải override hashCode, dùng cùng một tập field. Key nên immutable. Có thể dùng record.

HashMap: các con số (OpenJDK 21)

Hằng sốGiá trịÝ nghĩa
DEFAULT_INITIAL_CAPACITY16Cấp phát lazy ở lần put đầu
DEFAULT_LOAD_FACTOR0.75threshold = cap × 0.75 = 12; put thứ 13 thì resize ×2
TREEIFY_THRESHOLD8Bucket ≥ 8 node thì cân nhắc chuyển thành cây đỏ-đen
MIN_TREEIFY_CAPACITY64Bảng < 64 thì resize thay vì treeify
UNTREEIFY_THRESHOLD6Cây ≤ 6 node (khi resize) thì chuyển lại thành list

put trong 5 bước

  1. hash = h ^ (h >>> 16) (key null có hash 0)
  2. index = (n - 1) & hash (n luôn là lũy thừa của 2)
  3. Bucket rỗng thì đặt node. Có rồi thì so hash, sau đó == hoặc equals; trùng key thì ghi đè value
  4. Không trùng thì nối vào cuối list; list ≥ 8 thì treeify (hoặc resize nếu bảng < 64)
  5. ++size > threshold thì resize ×2

get: trung bình O(1); xấu nhất O(log n) với cây, O(n) với list. Không thread-safe: dùng ConcurrentHashMap khi có nhiều thread.
