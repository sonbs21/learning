REST với Spring MVC

Cheat sheet · từ Bài 6

Khung controller

@RestController
@RequestMapping("/products")
public class ProductController {

    private final ProductService productService;            // tiêm qua constructor

    public ProductController(ProductService productService) { this.productService = productService; }

    @GetMapping                                  // GET /products
    public List<Product> findAll() { ... }

    @GetMapping("/{id}")                         // GET /products/1
    public Product findById(@PathVariable Long id) { ... }

    @GetMapping("/search")                       // GET /products/search?maxPrice=100
    public List<Product> search(@RequestParam(required = false) Long maxPrice) { ... }

    @PostMapping                                 // POST /products + body JSON
    @ResponseStatus(HttpStatus.CREATED)
    public Product create(@RequestBody Product request) { ... }
}

Status code

MãKhi nàoCách trả
200 OKThành công (mặc định)Trả về object bình thường
201 CreatedTạo mới thành công@ResponseStatus(HttpStatus.CREATED)
204 No ContentThành công, không có body (ví dụ khi xoá)@ResponseStatus(HttpStatus.NO_CONTENT)
400 Bad RequestRequest sai định dạng (ví dụ /products/abc)Spring tự trả
404 Not FoundKhông có tài nguyênthrow new ResponseStatusException(HttpStatus.NOT_FOUND)

Gọi thử bằng curl

curl -i localhost:8080/products
curl -i -X POST localhost:8080/products -H 'Content-Type: application/json' -d '{"name":"Áo","price":1}'

Ghi nhớ

  • Controller và service đều là bean singleton: mọi request dùng chung, nên state dùng chung phải an toàn đa luồng (ConcurrentHashMap, AtomicLong).
  • Object ↔ JSON do Jackson làm, và Spring Boot đã tự cấu hình sẵn Jackson.
  • Dữ liệu trong RAM sẽ mất khi khởi động lại app, nên cần database.
