Thuật ngữ

Mọi bài học đều dùng đúng các từ dưới đây. Mỗi thuật ngữ có nguồn chuẩn đi kèm.

Thuật ngữNghĩaNguồn · Bài
JVM stackVùng nhớ riêng của mỗi thread, chứa các frame. Stack quá sâu (ví dụ đệ quy vô hạn) sẽ gây StackOverflowError.JVMS §2.5.2 · B1
FrameĐược tạo ra mỗi lần gọi method và huỷ khi method kết thúc. Chứa biến local, tham số và operand stack.JVMS §2.6 · B1
Biến localBiến khai báo trong method, kể cả tham số. Nằm trong frame.JVMS §2.6.1 · B1
HeapVùng nhớ dùng chung cho mọi thread, nơi cấp phát mọi object và mảng. Do GC quản lý.JVMS §2.5.3 · B1
ObjectInstance của một class, hoặc một mảng. Luôn nằm trên heap theo mô hình của spec.JLS §4.3.1 · B1
Primitive type8 kiểu: byte short int long float double char boolean. Biến chứa trực tiếp giá trị.JLS §4.2 · B1
Reference typeClass, interface, mảng, type variable. Biến chứa giá trị tham chiếu hoặc null.JLS §4.3 · B1
Giá trị tham chiếu (reference)“Con trỏ” tới một object. Java không cho làm phép toán số học trên nó như trong C.JLS §4.3.1 · B1
Pass-by-valueKhi gọi method, giá trị của đối số được copy vào một biến tham số mới. Java chỉ có cơ chế này.JLS §8.4.1 · B1
Garbage collector (GC)Cơ chế tự động thu hồi object trên heap khi không còn được tham chiếu tới. Object không bao giờ bị giải phóng thủ công.JVMS §2.5.3 · B1
Intern / String poolCơ chế dùng chung một instance String cho các literal và biểu thức hằng giống nhau.JLS §3.10.5 · B2
Biểu thức hằng (constant expression)Biểu thức compiler tính được ngay lúc compile, ví dụ "h" + "i" hoặc phép toán trên constant variable.JLS §15.29 · B2, B5
Boxing / Integer cacheTự đổi primitive sang wrapper. Các giá trị −128..127 luôn dùng chung object.JLS §5.1.7 · B2
Hợp đồng equals/hashCodeequals bằng nhau ⇒ hashCode bằng nhau. Chiều ngược lại không bắt buộc.Object Javadoc · B3
CollisionHai key khác nhau rơi vào cùng bucket (do cùng hash, hoặc khác hash nhưng cùng chỉ số).B3, B4
BucketMột ô trong mảng table của HashMap, chứa linked list hoặc cây các node.HashMap.java · B4
Load factor / thresholdNgưỡng đầy (mặc định 0.75). Khi size vượt capacity × load factor thì bảng gấp đôi.B4
TreeifyChuyển bucket từ list sang cây đỏ-đen khi có ≥ 8 node và bảng ≥ 64 ô.B4
Bytecode / instructionLệnh của JVM trong file .class, xem được bằng javap -c.JVMS ch.6 · B5
Operand stack“Bàn nháp” của frame: instruction đẩy giá trị lên, lấy ra để tính, rồi đẩy kết quả lại.JVMS §2.6.2 · B5
Local variable slotVị trí đánh số 0, 1, 2… của biến local trong frame. Slot 0 là this nếu là method instance.JVMS §2.6.1 · B5
ReachableCòn đi tới được từ một thread đang sống. Object không reachable là rác.JLS §12.6.1 · B6
GC rootsĐiểm xuất phát khi GC đánh dấu: biến local trong các frame đang sống, field static…B6
Young / old generationVùng cho object mới (eden + survivor) và vùng cho object sống lâu.G1 guide · B6
Memory leak (Java)Object không còn cần nhưng vẫn reachable, nên GC không được thu hồi.B6
