Ưu tiên 2 · Debug production và hiểu Spring sâu hơn

Chủ đềVì sao cần
ClassLoader hierarchy, parent delegationSpring Boot fat jar, lỗi ClassNotFoundException / NoClassDefFoundError, leak Metaspace (bài 2).
ThreadLocal và leak trong thread poolSpring lưu transaction, security context trong ThreadLocal. Quên dọn thì dữ liệu "lọt" sang request khác.
CompletableFuture, ReentrantLock, CountDownLatch, SemaphoreGọi nhiều service song song, giới hạn số kết nối. Hoàn thiện phần đa luồng.
Phân tích heap dump (Eclipse MAT) và Java Flight Recorder (jcmd JFR.start)Bài 9 mới chụp heap dump, chưa đọc. JFR là công cụ profiling có sẵn trong JDK, dùng được trên production.
Weak/Soft reference, các loại OutOfMemoryErrorHiểu cache tự giải phóng, phân biệt OOM heap / Metaspace / "unable to create native thread".
GC collector: G1 vs ZGC, tinh chỉnh cơ bảnChọn collector khi gặp pause dài. Nối tiếp bài 9.

Ưu tiên 3 · Nên biết, học khi cần

  • Java hiện đại: record, enum (EnumMap, singleton), sealed class, pattern matching cho switch (Java 21).
  • java.time: Instant, LocalDateTime, múi giờ. Lỗi giờ giấc rất hay gặp trong backend.
  • I/O: java.io vs NIO, charset/encoding (UTF-8), đọc file lớn.
  • Serialization và rủi ro bảo mật của nó; JPMS (module), chỉ cần biết ở mức đọc hiểu.

Rất nên làm: ôn tập tổng hợp

Bạn đã học 23 bài nhưng chưa gửi kết quả quiz hay lời giải thử thách nào. Agent vì vậy chưa biết phần nào bạn đã vững, phần nào chưa. Một bài ôn tập trộn (câu hỏi từ nhiều bài xen kẽ, kèm vài tình huống production giả lập như "app treo", "OOM", "@Transactional không rollback") sẽ giúp nhớ lâu hơn nhiều so với học thêm bài mới, và cho agent biết nên dạy gì tiếp.
