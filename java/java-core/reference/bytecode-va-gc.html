Bytecode & GC

Tra nhanh khi đọc javap hoặc log GC.

Lệnh

javac -d out File.java && javap -c -p -cp out ClassName   # xem bytecode
java -Xlog:gc File.java                                    # log GC
java -Xmx64m ...                                           # giới hạn heap
java -XX:+PrintCommandLineFlags -version                   # xem GC mặc định

Instruction hay gặp

InstructionLàm gì
iload_n / aload_nĐẩy int / reference từ local slot n lên operand stack
istore_n / astore_nLấy từ operand stack, cất vào slot n
iconst_n / bipush / ldcĐẩy hằng (số nhỏ / byte / từ constant pool, gồm cả String literal)
iadd, isub, imul…Lấy 2 toán hạng, tính, đẩy kết quả
new → dup → invokespecial <init>Cấp phát, nhân đôi tham chiếu, gọi constructor
getfield / putfieldĐọc / ghi field của object (đi theo tham chiếu)
invokestatic / invokevirtualGọi method static / method instance (dynamic dispatch)
invokedynamic makeConcatWithConstantsNối chuỗi lúc runtime (Java 9+)
ireturn / areturn / returnTrả về int / reference / void

Slot 0 là this (method instance) hoặc tham số đầu tiên (method static).

GC

Rác = không còn reachable từ GC roots (biến local của các thread đang sống, field static…). Tham chiếu vòng không cứu được object. System.gc() chỉ là gợi ý.
Leak trong Java = object vô dụng nhưng vẫn reachable.
