# Điểm xuất phát: viết được Java, chưa hiểu bên dưới

Người học tự đánh giá (2026-11-15): viết được code Java (class, interface, collection, OOP cơ bản) nhưng chưa hiểu JVM. Muốn cả 3 hướng: phỏng vấn/nền Spring, debug production, hiểu JVM. Vì vậy không dạy lại cú pháp; bắt đầu từ pipeline source → bytecode → JVM, rồi tới bộ nhớ.
