# 9.2.1. Redis

> Nguồn: <https://docs.spring.io/spring-boot/docs/3.2.5/reference/htmlsingle/#data.nosql.redis>

[Redis](https://redis.io/) là một cache, message broker, và kho key-value giàu tính năng. Spring Boot cung cấp auto-configuration cơ bản cho các thư viện client [Lettuce](https://github.com/lettuce-io/lettuce-core/) và [Jedis](https://github.com/xetorthio/jedis/) cùng các abstraction bên trên chúng do [Spring Data Redis](https://github.com/spring-projects/spring-data-redis) cung cấp.

Có một "Starter" `spring-boot-starter-data-redis` để tập hợp các dependency một cách tiện lợi. Theo mặc định, nó dùng [Lettuce](https://github.com/lettuce-io/lettuce-core/). Starter đó xử lý cả ứng dụng truyền thống lẫn reactive.

> **MẸO (TIP):** Chúng tôi cũng cung cấp một "Starter" `spring-boot-starter-data-redis-reactive` để nhất quán với các kho khác có hỗ trợ reactive.

## Kết nối tới Redis (Connecting to Redis)

Bạn có thể inject một instance `RedisConnectionFactory`, `StringRedisTemplate`, hoặc `RedisTemplate` thông thường đã được tự động cấu hình giống như bất kỳ Spring Bean nào khác. Đoạn sau cho thấy một ví dụ về bean như vậy:

**Java**

```java
import org.springframework.data.redis.core.StringRedisTemplate;
import org.springframework.stereotype.Component;

@Component
public class MyBean {

    private final StringRedisTemplate template;

    public MyBean(StringRedisTemplate template) {
        this.template = template;
    }

    // ...

    public Boolean someMethod() {
        return this.template.hasKey("spring");
    }

}
```

**Kotlin**

```kotlin
import org.springframework.data.redis.core.StringRedisTemplate
import org.springframework.stereotype.Component

@Component
class MyBean(private val template: StringRedisTemplate) {

    // ...

    fun someMethod(): Boolean {
        return template.hasKey("spring")
    }

}
```

Theo mặc định, instance cố gắng kết nối tới một Redis server tại `localhost:6379`. Bạn có thể chỉ định các chi tiết kết nối tùy chỉnh bằng các property `spring.data.redis.*`, như trong ví dụ sau:

**Properties**

```properties
spring.data.redis.host=localhost
spring.data.redis.port=6379
spring.data.redis.database=0
spring.data.redis.username=user
spring.data.redis.password=secret
```

**Yaml**

```yaml
spring:
  data:
    redis:
      host: "localhost"
      port: 6379
      database: 0
      username: "user"
      password: "secret"
```

> **MẸO (TIP):** Bạn cũng có thể đăng ký một số lượng tùy ý các bean hiện thực `LettuceClientConfigurationBuilderCustomizer` để tùy chỉnh nâng cao hơn. `ClientResources` cũng có thể được tùy chỉnh bằng `ClientResourcesBuilderCustomizer`. Nếu bạn dùng Jedis, `JedisClientConfigurationBuilderCustomizer` cũng có sẵn. Ngoài ra, bạn có thể đăng ký một bean kiểu `RedisStandaloneConfiguration`, `RedisSentinelConfiguration`, hoặc `RedisClusterConfiguration` để kiểm soát hoàn toàn cấu hình.

Nếu bạn thêm `@Bean` của riêng mình thuộc bất kỳ kiểu nào được tự động cấu hình, nó sẽ thay thế bean mặc định (ngoại trừ trường hợp `RedisTemplate`, khi việc loại trừ dựa trên tên bean, `redisTemplate`, chứ không phải kiểu của nó).

Theo mặc định, một connection factory có pooling được tự động cấu hình nếu `commons-pool2` nằm trên classpath.

`RedisConnectionFactory` được tự động cấu hình có thể được cấu hình để dùng SSL khi giao tiếp với server bằng cách đặt các property như trong ví dụ này:

**Properties**

```properties
spring.data.redis.ssl.enabled=true
```

**Yaml**

```yaml
spring:
  data:
    redis:
      ssl:
        enabled: true
```

Tài liệu tin cậy SSL tùy chỉnh có thể được cấu hình trong một [SSL bundle](https://docs.spring.io/spring-boot/docs/3.2.5/reference/htmlsingle/#features.ssl) và được áp dụng cho `RedisConnectionFactory` như trong ví dụ này:

**Properties**

```properties
spring.data.redis.ssl.bundle=example
```

**Yaml**

```yaml
spring:
  data:
    redis:
      ssl:
        bundle: "example"
```
