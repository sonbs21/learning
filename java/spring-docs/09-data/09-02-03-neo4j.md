# 9.2.3. Neo4j

> Nguồn: <https://docs.spring.io/spring-boot/docs/3.2.5/reference/htmlsingle/#data.nosql.neo4j>

[Neo4j](https://neo4j.com/) là một database đồ thị (graph database) NoSQL mã nguồn mở, dùng một mô hình dữ liệu phong phú gồm các node được kết nối bởi các quan hệ hạng nhất (first class relationship), phù hợp với dữ liệu lớn có tính kết nối hơn so với các cách tiếp cận RDBMS truyền thống. Spring Boot cung cấp một số tiện ích để làm việc với Neo4j, bao gồm "Starter" `spring-boot-starter-data-neo4j`.

## Kết nối tới database Neo4j (Connecting to a Neo4j Database)

Để truy cập một Neo4j server, bạn có thể inject một `org.neo4j.driver.Driver` đã được tự động cấu hình. Theo mặc định, instance cố gắng kết nối tới một Neo4j server tại `localhost:7687` bằng giao thức Bolt. Ví dụ sau cho thấy cách inject một `Driver` Neo4j, cho phép bạn truy cập, ngoài những thứ khác, một `Session`:

**Java**

```java
import org.neo4j.driver.Driver;
import org.neo4j.driver.Session;
import org.neo4j.driver.Values;

import org.springframework.stereotype.Component;

@Component
public class MyBean {

    private final Driver driver;

    public MyBean(Driver driver) {
        this.driver = driver;
    }

    // ...

    public String someMethod(String message) {
        try (Session session = this.driver.session()) {
            return session.executeWrite(
                    (transaction) -> transaction
                        .run("CREATE (a:Greeting) SET a.message = $message RETURN a.message + ', from node ' + id(a)",
                                Values.parameters("message", message))
                        .single()
                        .get(0)
                        .asString());
        }
    }

}
```

**Kotlin**

```kotlin
import org.neo4j.driver.*
import org.springframework.stereotype.Component

@Component
class MyBean(private val driver: Driver) {

    // ...

    fun someMethod(message: String?): String {
        driver.session().use { session ->
            return@someMethod session.executeWrite { transaction: TransactionContext ->
                transaction
                    .run(
                        "CREATE (a:Greeting) SET a.message = \$message RETURN a.message + ', from node ' + id(a)",
                        Values.parameters("message", message)
                    )
                    .single()[0].asString()
            }
        }
    }

}
```

Bạn có thể cấu hình nhiều khía cạnh của driver bằng các property `spring.neo4j.*`. Ví dụ sau cho thấy cách cấu hình uri và thông tin xác thực cần dùng:

**Properties**

```properties
spring.neo4j.uri=bolt://my-server:7687
spring.neo4j.authentication.username=neo4j
spring.neo4j.authentication.password=secret
```

**Yaml**

```yaml
spring:
  neo4j:
    uri: "bolt://my-server:7687"
    authentication:
      username: "neo4j"
      password: "secret"
```

`Driver` được tự động cấu hình được tạo bằng `ConfigBuilder`. Để tinh chỉnh cấu hình của nó, hãy khai báo một hoặc nhiều bean `ConfigBuilderCustomizer`. Mỗi bean sẽ được gọi theo thứ tự với `ConfigBuilder` được dùng để xây dựng `Driver`.

## Repository Spring Data Neo4j (Spring Data Neo4j Repositories)

Spring Data bao gồm hỗ trợ repository cho Neo4j. Để biết đầy đủ chi tiết về Spring Data Neo4j, xem [tài liệu tham khảo](https://docs.spring.io/spring-data/neo4j/docs/7.2.5/reference/html/).

Spring Data Neo4j dùng chung hạ tầng với Spring Data JPA, giống như nhiều module Spring Data khác. Bạn có thể lấy ví dụ JPA ở trên và định nghĩa `City` là một `@Node` của Spring Data Neo4j thay vì một `@Entity` JPA, và abstraction repository hoạt động theo cùng cách, như trong ví dụ sau:

**Java**

```java
import java.util.Optional;

import org.springframework.data.neo4j.repository.Neo4jRepository;

public interface CityRepository extends Neo4jRepository<City, Long> {

    Optional<City> findOneByNameAndState(String name, String state);

}
```

**Kotlin**

```kotlin
import org.springframework.data.neo4j.repository.Neo4jRepository
import java.util.Optional

interface CityRepository : Neo4jRepository<City?, Long?> {

    fun findOneByNameAndState(name: String?, state: String?): Optional<City?>?

}
```

"Starter" `spring-boot-starter-data-neo4j` bật hỗ trợ repository cũng như quản lý transaction. Spring Boot hỗ trợ cả repository Neo4j cổ điển và reactive, dùng các bean `Neo4jTemplate` hoặc `ReactiveNeo4jTemplate`. Khi Project Reactor có trên classpath, kiểu reactive cũng được tự động cấu hình.

Repository và entity được tìm thấy thông qua việc quét. Theo mặc định, các [package auto-configuration](https://docs.spring.io/spring-boot/docs/3.2.5/reference/htmlsingle/#using.auto-configuration.packages) được quét. Bạn có thể tùy chỉnh các vị trí tìm kiếm repository và entity bằng cách dùng lần lượt `@EnableNeo4jRepositories` và `@EntityScan`.

> **LƯU Ý (NOTE):** Trong một ứng dụng dùng kiểu reactive, `ReactiveTransactionManager` không được tự động cấu hình. Để bật quản lý transaction, bean sau phải được định nghĩa trong cấu hình của bạn:

**Java**

```java
import org.neo4j.driver.Driver;

import org.springframework.context.annotation.Bean;
import org.springframework.context.annotation.Configuration;
import org.springframework.data.neo4j.core.ReactiveDatabaseSelectionProvider;
import org.springframework.data.neo4j.core.transaction.ReactiveNeo4jTransactionManager;

@Configuration(proxyBeanMethods = false)
public class MyNeo4jConfiguration {

    @Bean
    public ReactiveNeo4jTransactionManager reactiveTransactionManager(Driver driver,
            ReactiveDatabaseSelectionProvider databaseNameProvider) {
        return new ReactiveNeo4jTransactionManager(driver, databaseNameProvider);
    }

}
```

**Kotlin**

```kotlin
import org.neo4j.driver.Driver
import org.springframework.context.annotation.Bean
import org.springframework.context.annotation.Configuration
import org.springframework.data.neo4j.core.ReactiveDatabaseSelectionProvider
import org.springframework.data.neo4j.core.transaction.ReactiveNeo4jTransactionManager

@Configuration(proxyBeanMethods = false)
class MyNeo4jConfiguration {

    @Bean
    fun reactiveTransactionManager(driver: Driver,
            databaseNameProvider: ReactiveDatabaseSelectionProvider): ReactiveNeo4jTransactionManager {
        return ReactiveNeo4jTransactionManager(driver, databaseNameProvider)
    }
}
```
