# 9.2. Làm việc với các công nghệ NoSQL (Working with NoSQL Technologies)

> Nguồn: <https://docs.spring.io/spring-boot/docs/3.2.5/reference/htmlsingle/#data.nosql>

Spring Data cung cấp các project bổ sung giúp bạn truy cập nhiều công nghệ NoSQL khác nhau, bao gồm:

- [Cassandra](https://spring.io/projects/spring-data-cassandra)
- [Couchbase](https://spring.io/projects/spring-data-couchbase)
- [Elasticsearch](https://spring.io/projects/spring-data-elasticsearch)
- [GemFire](https://spring.io/projects/spring-data-gemfire) hoặc [Geode](https://spring.io/projects/spring-data-geode)
- [LDAP](https://spring.io/projects/spring-data-ldap)
- [MongoDB](https://spring.io/projects/spring-data-mongodb)
- [Neo4J](https://spring.io/projects/spring-data-neo4j)
- [Redis](https://spring.io/projects/spring-data-redis)

Trong số này, Spring Boot cung cấp auto-configuration cho Cassandra, Couchbase, Elasticsearch, LDAP, MongoDB, Neo4J và Redis. Ngoài ra, [Spring Boot for Apache Geode](https://github.com/spring-projects/spring-boot-data-geode) cung cấp [auto-configuration cho Apache Geode](https://docs.spring.io/spring-boot-data-geode-build/2.0.x/reference/html5/#geode-repositories). Bạn có thể dùng các project khác, nhưng bạn phải tự cấu hình chúng. Xem tài liệu tham khảo phù hợp tại [spring.io/projects/spring-data](https://spring.io/projects/spring-data).

Spring Boot cũng cung cấp auto-configuration cho client InfluxDB nhưng nó đã bị deprecated để ưu tiên [client Java InfluxDB mới](https://github.com/influxdata/influxdb-client-java), vốn cung cấp tích hợp Spring Boot riêng.
