# 9.2.7. LDAP

> Nguồn: <https://docs.spring.io/spring-boot/docs/3.2.5/reference/htmlsingle/#data.nosql.ldap>

[LDAP](https://en.wikipedia.org/wiki/Lightweight_Directory_Access_Protocol) (Lightweight Directory Access Protocol) là một giao thức ứng dụng tiêu chuẩn công nghiệp, mở, không phụ thuộc nhà cung cấp, dùng để truy cập và duy trì các dịch vụ thông tin thư mục phân tán qua mạng IP. Spring Boot cung cấp auto-configuration cho bất kỳ LDAP server tương thích nào cũng như hỗ trợ cho LDAP server nhúng in-memory từ [UnboundID](https://ldap.com/unboundid-ldap-sdk-for-java/).

Các abstraction LDAP được cung cấp bởi [Spring Data LDAP](https://github.com/spring-projects/spring-data-ldap). Có một "Starter" `spring-boot-starter-data-ldap` để tập hợp các dependency một cách tiện lợi.

## Kết nối tới LDAP server (Connecting to an LDAP Server)

Để kết nối tới một LDAP server, hãy đảm bảo bạn khai báo dependency tới "Starter" `spring-boot-starter-data-ldap` hoặc `spring-ldap-core`, rồi khai báo các URL của server trong application.properties, như trong ví dụ sau:

**Properties**

```properties
spring.ldap.urls=ldap://myserver:1235
spring.ldap.username=admin
spring.ldap.password=secret
```

**Yaml**

```yaml
spring:
  ldap:
    urls: "ldap://myserver:1235"
    username: "admin"
    password: "secret"
```

Nếu bạn cần tùy chỉnh các thiết lập kết nối, bạn có thể dùng các property `spring.ldap.base` và `spring.ldap.base-environment`.

Một `LdapContextSource` được tự động cấu hình dựa trên các thiết lập này. Nếu có bean `DirContextAuthenticationStrategy`, nó sẽ được gắn với `LdapContextSource` được tự động cấu hình. Nếu bạn cần tùy chỉnh nó, ví dụ để dùng `PooledContextSource`, bạn vẫn có thể inject `LdapContextSource` được tự động cấu hình. Hãy đảm bảo đánh dấu `ContextSource` đã tùy chỉnh của bạn là `@Primary` để `LdapTemplate` được tự động cấu hình dùng nó.

## Repository Spring Data LDAP (Spring Data LDAP Repositories)

Spring Data bao gồm hỗ trợ repository cho LDAP.

Repository và document được tìm thấy thông qua việc quét. Theo mặc định, các [package auto-configuration](https://docs.spring.io/spring-boot/docs/3.2.5/reference/htmlsingle/#using.auto-configuration.packages) được quét. Bạn có thể tùy chỉnh các vị trí tìm kiếm repository và document bằng cách dùng lần lượt `@EnableLdapRepositories` và `@EntityScan`.

Để biết đầy đủ chi tiết về Spring Data LDAP, xem [tài liệu tham khảo](https://docs.spring.io/spring-data/ldap/docs/1.0.x/reference/html/).

Bạn cũng có thể inject một instance `LdapTemplate` đã được tự động cấu hình giống như với bất kỳ Spring Bean nào khác, như trong ví dụ sau:

**Java**

```java
import java.util.List;

import org.springframework.ldap.core.LdapTemplate;
import org.springframework.stereotype.Component;

@Component
public class MyBean {

    private final LdapTemplate template;

    public MyBean(LdapTemplate template) {
        this.template = template;
    }

    // ...

    public List<User> someMethod() {
        return this.template.findAll(User.class);
    }

}
```

**Kotlin**

```kotlin
import org.springframework.ldap.core.LdapTemplate
import org.springframework.stereotype.Component

@Component
class MyBean(private val template: LdapTemplate) {

    // ...

    fun someMethod(): List<User> {
        return template.findAll(User::class.java)
    }

}
```

## LDAP server nhúng in-memory (Embedded In-memory LDAP Server)

Cho mục đích kiểm thử, Spring Boot hỗ trợ auto-configuration của một LDAP server in-memory từ [UnboundID](https://ldap.com/unboundid-ldap-sdk-for-java/). Để cấu hình server, hãy thêm dependency tới `com.unboundid:unboundid-ldapsdk` và khai báo property `spring.ldap.embedded.base-dn`, như sau:

**Properties**

```properties
spring.ldap.embedded.base-dn=dc=spring,dc=io
```

**Yaml**

```yaml
spring:
  ldap:
    embedded:
      base-dn: "dc=spring,dc=io"
```

> **LƯU Ý (NOTE):** Có thể định nghĩa nhiều giá trị base-dn, tuy nhiên, vì các distinguished name thường chứa dấu phẩy, chúng phải được định nghĩa bằng ký hiệu đúng.
>
> Trong file yaml, bạn có thể dùng ký hiệu danh sách yaml. Trong file properties, bạn phải đưa index vào như một phần của tên property:

**Properties**

```properties
spring.ldap.embedded.base-dn[0]=dc=spring,dc=io
spring.ldap.embedded.base-dn[1]=dc=vmware,dc=com
```

**Yaml**

```yaml
spring.ldap.embedded.base-dn:
  - "dc=spring,dc=io"
  - "dc=vmware,dc=com"
```

Theo mặc định, server khởi động trên một cổng ngẫu nhiên và kích hoạt hỗ trợ LDAP thông thường. Không cần chỉ định property `spring.ldap.urls`.

Nếu có file `schema.ldif` trên classpath, nó được dùng để khởi tạo server. Nếu bạn muốn nạp script khởi tạo từ một resource khác, bạn cũng có thể dùng property `spring.ldap.embedded.ldif`.

Theo mặc định, một schema tiêu chuẩn được dùng để kiểm tra (validate) các file `LDIF`. Bạn có thể tắt hoàn toàn việc kiểm tra bằng cách đặt property `spring.ldap.embedded.validation.enabled`. Nếu bạn có các thuộc tính tùy chỉnh, bạn có thể dùng `spring.ldap.embedded.validation.schema` để định nghĩa các kiểu thuộc tính hoặc object class tùy chỉnh.
