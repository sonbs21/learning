# 9.3. Đọc gì tiếp theo (What to Read Next)

> Nguồn: <https://docs.spring.io/spring-boot/docs/3.2.5/reference/htmlsingle/#data.whats-next>

Giờ đây bạn đã có cảm nhận về cách dùng Spring Boot với nhiều công nghệ dữ liệu khác nhau. Từ đây, bạn có thể đọc về hỗ trợ của Spring Boot cho nhiều [công nghệ messaging](https://docs.spring.io/spring-boot/docs/3.2.5/reference/htmlsingle/#messaging) khác nhau và cách bật chúng trong ứng dụng.
