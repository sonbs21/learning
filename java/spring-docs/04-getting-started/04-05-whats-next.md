# 4.5. Đọc gì tiếp theo (What to Read Next)

> Nguồn: <https://docs.spring.io/spring-boot/docs/3.2.5/reference/htmlsingle/#getting-started.whats-next>

Hy vọng phần này đã cung cấp cho bạn một số kiến thức cơ bản về Spring Boot và giúp bạn bắt đầu viết ứng dụng của riêng mình. Nếu bạn là kiểu lập trình viên hướng nhiệm vụ (task-oriented), bạn có thể muốn chuyển sang [spring.io](https://spring.io) và làm theo một số hướng dẫn [getting started](https://spring.io/guides/) giải quyết các vấn đề cụ thể kiểu "Làm thế nào để làm điều đó với Spring?". Chúng tôi cũng có tài liệu tham khảo "[How-to](https://docs.spring.io/spring-boot/docs/3.2.5/reference/htmlsingle/#howto)" dành riêng cho Spring Boot.

Nếu không, bước hợp lý tiếp theo là đọc *[Phát triển với Spring Boot (Developing with Spring Boot)](https://docs.spring.io/spring-boot/docs/3.2.5/reference/htmlsingle/#using)*. Nếu bạn thực sự sốt ruột, bạn cũng có thể nhảy trước và đọc về *[Các tính năng của Spring Boot (Spring Boot features)](https://docs.spring.io/spring-boot/docs/3.2.5/reference/htmlsingle/#features)*.
