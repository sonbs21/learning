# 4. Bắt đầu (Getting Started)

> Nguồn: <https://docs.spring.io/spring-boot/docs/3.2.5/reference/htmlsingle/#getting-started>

Nếu bạn mới bắt đầu với Spring Boot, hoặc với "Spring" nói chung, hãy bắt đầu bằng việc đọc phần này. Nó trả lời các câu hỏi cơ bản "cái gì?", "như thế nào?" và "tại sao?". Phần này bao gồm phần giới thiệu về Spring Boot, cùng với hướng dẫn cài đặt. Sau đó, chúng tôi sẽ hướng dẫn bạn từng bước xây dựng ứng dụng Spring Boot đầu tiên, đồng thời thảo luận một số nguyên lý cốt lõi trong quá trình đó.
