# 10.2. AMQP

> Nguồn: <https://docs.spring.io/spring-boot/docs/3.2.5/reference/htmlsingle/#messaging.amqp>

Advanced Message Queuing Protocol (AMQP) là một giao thức ở cấp đường truyền (wire-level), không phụ thuộc nền tảng, dành cho middleware hướng message. Project Spring AMQP áp dụng các khái niệm cốt lõi của Spring vào việc phát triển các giải pháp messaging dựa trên AMQP. Spring Boot cung cấp một số tiện ích để làm việc với AMQP thông qua RabbitMQ, bao gồm "Starter" `spring-boot-starter-amqp`.
