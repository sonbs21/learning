# 10.1. JMS

> Nguồn: <https://docs.spring.io/spring-boot/docs/3.2.5/reference/htmlsingle/#messaging.jms>

Interface `jakarta.jms.ConnectionFactory` cung cấp một phương thức tiêu chuẩn để tạo một `jakarta.jms.Connection` dùng để tương tác với một JMS broker. Mặc dù Spring cần một `ConnectionFactory` để làm việc với JMS, bạn thường không cần tự dùng nó trực tiếp mà có thể dựa vào các abstraction messaging cấp cao hơn. (Xem [phần liên quan](https://docs.spring.io/spring-framework/reference/6.1/integration/jms.html) trong tài liệu tham khảo Spring Framework để biết chi tiết.) Spring Boot cũng tự động cấu hình hạ tầng cần thiết để gửi và nhận message.
