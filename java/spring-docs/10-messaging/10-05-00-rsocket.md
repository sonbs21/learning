# 10.5. RSocket

> Nguồn: <https://docs.spring.io/spring-boot/docs/3.2.5/reference/htmlsingle/#messaging.rsocket>

[RSocket](https://rsocket.io) là một giao thức nhị phân dùng trên các transport dạng luồng byte (byte stream). Nó cho phép các mô hình tương tác đối xứng thông qua việc truyền message bất đồng bộ trên một kết nối duy nhất.

Module `spring-messaging` của Spring Framework cung cấp hỗ trợ cho các requester và responder RSocket, ở cả phía client và phía server. Xem [phần RSocket](https://docs.spring.io/spring-framework/reference/6.1/rsocket.html#rsocket-spring) trong tài liệu tham khảo Spring Framework để biết thêm chi tiết, bao gồm tổng quan về giao thức RSocket.
