# 10. Messaging

> Nguồn: <https://docs.spring.io/spring-boot/docs/3.2.5/reference/htmlsingle/#messaging>

Spring Framework cung cấp hỗ trợ rộng rãi cho việc tích hợp với các hệ thống messaging, từ việc dùng JMS API một cách đơn giản hóa bằng `JmsTemplate` đến một hạ tầng hoàn chỉnh để nhận message bất đồng bộ. Spring AMQP cung cấp một bộ tính năng tương tự cho Advanced Message Queuing Protocol. Spring Boot cũng cung cấp các tùy chọn auto-configuration cho `RabbitTemplate` và RabbitMQ. Spring WebSocket có sẵn hỗ trợ cho messaging STOMP, và Spring Boot hỗ trợ điều đó thông qua các starter và một chút auto-configuration. Spring Boot cũng hỗ trợ Apache Kafka và Apache Pulsar.
