# 3. Tổng quan tài liệu (Documentation Overview)

> Nguồn: <https://docs.spring.io/spring-boot/docs/3.2.5/reference/htmlsingle/#documentation>

Phần này cung cấp cái nhìn tổng quan ngắn gọn về tài liệu tham khảo của Spring Boot. Nó đóng vai trò như một bản đồ cho phần còn lại của tài liệu.

Bản mới nhất của tài liệu này có tại [docs.spring.io/spring-boot/docs/current/reference/](https://docs.spring.io/spring-boot/docs/current/reference/).
