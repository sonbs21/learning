- Kiểm thử (Testing): [JVM](https://docs.spring.io/spring-boot/docs/3.2.5/reference/htmlsingle/#native-image.testing.with-the-jvm) | [Native Build Tools](https://docs.spring.io/spring-boot/docs/3.2.5/reference/htmlsingle/#native-image.testing.with-native-build-tools)
