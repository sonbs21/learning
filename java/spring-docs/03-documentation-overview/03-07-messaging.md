- Kafka: [Auto-configuration cho Spring Kafka](https://docs.spring.io/spring-boot/docs/3.2.5/reference/htmlsingle/#messaging.kafka)
- Pulsar: [Auto-configuration cho Spring for Apache Pulsar](https://docs.spring.io/spring-boot/docs/3.2.5/reference/htmlsingle/#messaging.pulsar)
- RSocket: [Auto-configuration cho hỗ trợ RSocket của Spring Framework](https://docs.spring.io/spring-boot/docs/3.2.5/reference/htmlsingle/#messaging.rsocket)
- Spring Integration: [Auto-configuration cho Spring Integration](https://docs.spring.io/spring-boot/docs/3.2.5/reference/htmlsingle/#messaging.spring-integration)
