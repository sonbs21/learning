# 3.10. Đưa lên Production (Moving to Production)

> Nguồn: <https://docs.spring.io/spring-boot/docs/3.2.5/reference/htmlsingle/#documentation.actuator>

Khi bạn đã sẵn sàng đưa ứng dụng Spring Boot lên production, chúng tôi có [một vài thủ thuật](https://docs.spring.io/spring-boot/docs/3.2.5/reference/htmlsingle/#actuator) mà có thể bạn sẽ thích:

- Management endpoint: [Tổng quan](https://docs.spring.io/spring-boot/docs/3.2.5/reference/htmlsingle/#actuator.endpoints)
- Tùy chọn kết nối: [HTTP](https://docs.spring.io/spring-boot/docs/3.2.5/reference/htmlsingle/#actuator.monitoring) | [JMX](https://docs.spring.io/spring-boot/docs/3.2.5/reference/htmlsingle/#actuator.jmx)
- Giám sát (Monitoring): [Metrics](https://docs.spring.io/spring-boot/docs/3.2.5/reference/htmlsingle/#actuator.metrics) | [Auditing](https://docs.spring.io/spring-boot/docs/3.2.5/reference/htmlsingle/#actuator.auditing) | [HTTP Exchanges](https://docs.spring.io/spring-boot/docs/3.2.5/reference/htmlsingle/#actuator.http-exchanges) | [Process](https://docs.spring.io/spring-boot/docs/3.2.5/reference/htmlsingle/#actuator.process-monitoring)
