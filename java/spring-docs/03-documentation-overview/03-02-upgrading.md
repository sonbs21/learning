# 3.2. Nâng cấp từ phiên bản cũ hơn (Upgrading From an Earlier Version)

> Nguồn: <https://docs.spring.io/spring-boot/docs/3.2.5/reference/htmlsingle/#documentation.upgrading>

Bạn nên luôn đảm bảo rằng mình đang chạy một [phiên bản được hỗ trợ](https://github.com/spring-projects/spring-boot/wiki/Supported-Versions) của Spring Boot.

Tùy thuộc vào phiên bản mà bạn nâng cấp lên, bạn có thể tìm thêm một số mẹo tại đây:

- Từ 1.x: [Nâng cấp từ 1.x](https://docs.spring.io/spring-boot/docs/3.2.5/reference/htmlsingle/#upgrading.from-1x)
- Lên một bản phát hành tính năng mới: [Nâng cấp lên bản phát hành tính năng mới](https://docs.spring.io/spring-boot/docs/3.2.5/reference/htmlsingle/#upgrading.to-feature)
- Spring Boot CLI: [Nâng cấp Spring Boot CLI](https://docs.spring.io/spring-boot/docs/3.2.5/reference/htmlsingle/#upgrading.cli)
