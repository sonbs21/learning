# 3.5. Web

> Nguồn: <https://docs.spring.io/spring-boot/docs/3.2.5/reference/htmlsingle/#documentation.web>

Nếu bạn phát triển ứng dụng web bằng Spring Boot, hãy xem các nội dung sau:

- Ứng dụng Web dạng Servlet: [Spring MVC, Jersey, Servlet Container nhúng](https://docs.spring.io/spring-boot/docs/3.2.5/reference/htmlsingle/#web.servlet)
- Ứng dụng Web dạng Reactive: [Spring Webflux, Servlet Container nhúng](https://docs.spring.io/spring-boot/docs/3.2.5/reference/htmlsingle/#web.reactive)
- Tắt ứng dụng nhẹ nhàng (Graceful Shutdown): [Graceful Shutdown](https://docs.spring.io/spring-boot/docs/3.2.5/reference/htmlsingle/#web.graceful-shutdown)
- Spring Security: [Cấu hình bảo mật mặc định, Auto-configuration cho OAuth2, SAML](https://docs.spring.io/spring-boot/docs/3.2.5/reference/htmlsingle/#web.security)
- Spring Session: [Auto-configuration cho Spring Session](https://docs.spring.io/spring-boot/docs/3.2.5/reference/htmlsingle/#web.spring-session)
- Spring HATEOAS: [Auto-configuration cho Spring HATEOAS](https://docs.spring.io/spring-boot/docs/3.2.5/reference/htmlsingle/#web.spring-hateoas)
