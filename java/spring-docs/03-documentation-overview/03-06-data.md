# 3.6. Dữ liệu (Data)

> Nguồn: <https://docs.spring.io/spring-boot/docs/3.2.5/reference/htmlsingle/#documentation.data>

Nếu ứng dụng của bạn làm việc với một kho dữ liệu (datastore), bạn có thể xem cách cấu hình tại đây:

- SQL: [Cấu hình SQL Datastore, hỗ trợ Database nhúng, Connection pool, và nhiều hơn nữa.](https://docs.spring.io/spring-boot/docs/3.2.5/reference/htmlsingle/#data.sql)
- NOSQL: [Auto-configuration cho các kho NOSQL như Redis, MongoDB, Neo4j, và các loại khác.](https://docs.spring.io/spring-boot/docs/3.2.5/reference/htmlsingle/#data.nosql)
