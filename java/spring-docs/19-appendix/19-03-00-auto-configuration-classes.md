# Phụ lục C: Các class auto-configuration (Appendix C: Auto-configuration Classes)

> Nguồn: <https://docs.spring.io/spring-boot/docs/3.2.5/reference/htmlsingle/#appendix.auto-configuration-classes>

Phụ lục này chứa chi tiết về tất cả các class auto-configuration do Spring Boot cung cấp, kèm theo link tới tài liệu và mã nguồn. Hãy nhớ xem thêm báo cáo điều kiện (conditions report) trong ứng dụng của bạn để biết thêm chi tiết về những tính năng nào đang được bật. (Để làm vậy, hãy khởi động ứng dụng với `--debug` hoặc `-Ddebug` hoặc, trong một ứng dụng Actuator, hãy dùng endpoint `conditions`).
