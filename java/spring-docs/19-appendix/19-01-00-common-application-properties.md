# Phụ lục A: Các property ứng dụng phổ biến (Appendix A: Common Application Properties)

> Nguồn: <https://docs.spring.io/spring-boot/docs/3.2.5/reference/htmlsingle/#appendix.application-properties>

Nhiều property khác nhau có thể được chỉ định bên trong file `application.properties`, bên trong file `application.yaml`, hoặc dưới dạng các switch dòng lệnh. Phụ lục này cung cấp danh sách các property Spring Boot phổ biến và tham chiếu tới các class bên dưới sử dụng chúng.

> **MẸO (TIP):** Spring Boot cung cấp nhiều cơ chế chuyển đổi khác nhau với định dạng giá trị nâng cao, hãy nhớ xem lại [phần chuyển đổi property](https://docs.spring.io/spring-boot/docs/3.2.5/reference/htmlsingle/#features.external-config.typesafe-configuration-properties.conversion).

> **LƯU Ý (NOTE):** Các property có thể được đóng góp từ các file jar bổ sung trên classpath, vì vậy bạn không nên coi đây là một danh sách đầy đủ. Ngoài ra, bạn có thể định nghĩa các property của riêng mình.
