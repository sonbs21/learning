| [`spring.devtools.remote.context-path`](https://docs.spring.io/spring-boot/docs/3.2.5/reference/htmlsingle/#application-properties.devtools.spring.devtools.remote.context-path) | Context path dùng để xử lý kết nối từ xa. | `/.~~spring-boot!~` |
| [`spring.devtools.remote.proxy.host`](https://docs.spring.io/spring-boot/docs/3.2.5/reference/htmlsingle/#application-properties.devtools.spring.devtools.remote.proxy.host) | Host của proxy dùng để kết nối tới ứng dụng từ xa. |  |
| [`spring.devtools.remote.proxy.port`](https://docs.spring.io/spring-boot/docs/3.2.5/reference/htmlsingle/#application-properties.devtools.spring.devtools.remote.proxy.port) | Port của proxy dùng để kết nối tới ứng dụng từ xa. |  |
| [`spring.devtools.remote.restart.enabled`](https://docs.spring.io/spring-boot/docs/3.2.5/reference/htmlsingle/#application-properties.devtools.spring.devtools.remote.restart.enabled) | Có bật khởi động lại từ xa hay không. | `true` |
| [`spring.devtools.remote.secret`](https://docs.spring.io/spring-boot/docs/3.2.5/reference/htmlsingle/#application-properties.devtools.spring.devtools.remote.secret) | Một shared secret cần thiết để thiết lập kết nối (bắt buộc để bật hỗ trợ từ xa). |  |
| [`spring.devtools.remote.secret-header-name`](https://docs.spring.io/spring-boot/docs/3.2.5/reference/htmlsingle/#application-properties.devtools.spring.devtools.remote.secret-header-name) | HTTP header dùng để truyền shared secret. | `X-AUTH-TOKEN` |
| [`spring.devtools.restart.additional-exclude`](https://docs.spring.io/spring-boot/docs/3.2.5/reference/htmlsingle/#application-properties.devtools.spring.devtools.restart.additional-exclude) | Các pattern bổ sung cần loại trừ khỏi việc kích hoạt khởi động lại toàn bộ. |  |
| [`spring.devtools.restart.additional-paths`](https://docs.spring.io/spring-boot/docs/3.2.5/reference/htmlsingle/#application-properties.devtools.spring.devtools.restart.additional-paths) | Các đường dẫn bổ sung cần theo dõi thay đổi. |  |
| [`spring.devtools.restart.enabled`](https://docs.spring.io/spring-boot/docs/3.2.5/reference/htmlsingle/#application-properties.devtools.spring.devtools.restart.enabled) | Có bật khởi động lại tự động hay không. | `true` |
| [`spring.devtools.restart.exclude`](https://docs.spring.io/spring-boot/docs/3.2.5/reference/htmlsingle/#application-properties.devtools.spring.devtools.restart.exclude) | Các pattern cần loại trừ khỏi việc kích hoạt khởi động lại toàn bộ. | `META-INF/maven/**,META-INF/resources/**,resources/**,static/**,public/**,templates/**,**/*Test.class,**/*Tests.class,git.properties,META-INF/build-info.properties` |

| [`spring.devtools.restart.poll-interval`](https://docs.spring.io/spring-boot/docs/3.2.5/reference/htmlsingle/#application-properties.devtools.spring.devtools.restart.poll-interval) | Khoảng thời gian chờ giữa các lần poll thay đổi classpath. | `1s` |

| [`spring.devtools.restart.trigger-file`](https://docs.spring.io/spring-boot/docs/3.2.5/reference/htmlsingle/#application-properties.devtools.spring.devtools.restart.trigger-file) | Tên của một file cụ thể mà khi thay đổi sẽ kích hoạt việc kiểm tra khởi động lại. Phải là tên đơn giản (không có đường dẫn) của một file xuất hiện trên classpath. Nếu không được chỉ định, mọi thay đổi file trên classpath đều kích hoạt khởi động lại. |  |
