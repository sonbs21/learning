# A.18. Property kiểm thử (Testing Properties)

> Nguồn: <https://docs.spring.io/spring-boot/docs/3.2.5/reference/htmlsingle/#appendix.application-properties.testing>

| Tên | Mô tả | Giá trị mặc định |
|---|---|---|
| [`spring.test.database.replace`](https://docs.spring.io/spring-boot/docs/3.2.5/reference/htmlsingle/#application-properties.testing.spring.test.database.replace) | Kiểu DataSource hiện có cần thay thế. | `any` |
| [`spring.test.mockmvc.print`](https://docs.spring.io/spring-boot/docs/3.2.5/reference/htmlsingle/#application-properties.testing.spring.test.mockmvc.print) | Tùy chọn MVC Print. | `default` |
| [`spring.test.observability.auto-configure`](https://docs.spring.io/spring-boot/docs/3.2.5/reference/htmlsingle/#application-properties.testing.spring.test.observability.auto-configure) | Observability có nên được auto-configure trong test hay không. | `false` |
