# 11.9. Đọc gì tiếp theo (What to Read Next)

> Nguồn: <https://docs.spring.io/spring-boot/docs/3.2.5/reference/htmlsingle/#io.whats-next>

Giờ đây bạn đã có hiểu biết tốt về [các tính năng cốt lõi](https://docs.spring.io/spring-boot/docs/3.2.5/reference/htmlsingle/#features) của Spring Boot và các công nghệ khác nhau mà Spring Boot hỗ trợ thông qua auto-configuration.

Các phần tiếp theo đi vào chi tiết về việc triển khai ứng dụng lên các nền tảng cloud. Bạn có thể đọc về [xây dựng container image](https://docs.spring.io/spring-boot/docs/3.2.5/reference/htmlsingle/#container-images) trong phần tiếp theo hoặc nhảy tới phần [các tính năng sẵn sàng cho production](https://docs.spring.io/spring-boot/docs/3.2.5/reference/htmlsingle/#actuator).
