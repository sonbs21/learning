# 11. IO

> Nguồn: <https://docs.spring.io/spring-boot/docs/3.2.5/reference/htmlsingle/#io>

Hầu hết các ứng dụng sẽ cần xử lý các vấn đề nhập/xuất (input/output) vào một thời điểm nào đó. Spring Boot cung cấp các tiện ích và tích hợp với nhiều công nghệ để hỗ trợ khi bạn cần các khả năng IO. Phần này đề cập đến các tính năng IO tiêu chuẩn như caching và validation cũng như các chủ đề nâng cao hơn như lập lịch và giao dịch phân tán. Chúng tôi cũng sẽ đề cập đến việc gọi các service REST hoặc SOAP từ xa và gửi email.
