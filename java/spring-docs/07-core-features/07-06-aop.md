# 7.6. Lập trình hướng khía cạnh (Aspect-Oriented Programming)

> Nguồn: <https://docs.spring.io/spring-boot/docs/3.2.5/reference/htmlsingle/#features.aop>

Spring Boot cung cấp auto-configuration cho lập trình hướng khía cạnh (aspect-oriented programming - AOP). Bạn có thể tìm hiểu thêm về AOP với Spring trong [tài liệu tham khảo Spring Framework](https://docs.spring.io/spring-framework/reference/6.1/core/aop-api.html).

Theo mặc định, auto-configuration của Spring Boot cấu hình Spring AOP để dùng proxy CGLib. Để dùng proxy JDK thay thế, hãy đặt `configprop:spring.aop.proxy-target-class` thành `false`.

Nếu AspectJ nằm trên classpath, auto-configuration của Spring Boot sẽ tự động bật AspectJ auto proxy, nên không cần đến `@EnableAspectJAutoProxy`.
