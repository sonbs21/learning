# 7. Các tính năng cốt lõi (Core Features)

> Nguồn: <https://docs.spring.io/spring-boot/docs/3.2.5/reference/htmlsingle/#features>

Phần này đi sâu vào các chi tiết của Spring Boot. Tại đây, bạn có thể tìm hiểu về các tính năng chính mà bạn có thể muốn sử dụng và tùy chỉnh. Nếu chưa đọc, bạn có thể muốn đọc các phần "[Bắt đầu (Getting Started)](https://docs.spring.io/spring-boot/docs/3.2.5/reference/htmlsingle/#getting-started)" và "[Phát triển với Spring Boot (Developing with Spring Boot)](https://docs.spring.io/spring-boot/docs/3.2.5/reference/htmlsingle/#using)" để có nền tảng vững chắc về các kiến thức cơ bản.
