# 7.15. Đọc gì tiếp theo (What to Read Next)

> Nguồn: <https://docs.spring.io/spring-boot/docs/3.2.5/reference/htmlsingle/#features.whats-next>

Nếu bạn muốn tìm hiểu thêm về bất kỳ class nào được thảo luận trong phần này, hãy xem [tài liệu API của Spring Boot](https://docs.spring.io/spring-boot/docs/3.2.5/api/) hoặc bạn có thể duyệt [trực tiếp mã nguồn](https://github.com/spring-projects/spring-boot/tree/v3.2.5). Nếu bạn có câu hỏi cụ thể, hãy xem phần [how-to](https://docs.spring.io/spring-boot/docs/3.2.5/reference/htmlsingle/#howto).

Nếu bạn đã nắm vững các tính năng cốt lõi của Spring Boot, bạn có thể tiếp tục và đọc về [các tính năng sẵn sàng cho production (production-ready features)](https://docs.spring.io/spring-boot/docs/3.2.5/reference/htmlsingle/#actuator).
