# 18.19. Triển khai truyền thống (Traditional Deployment)

> Nguồn: <https://docs.spring.io/spring-boot/docs/3.2.5/reference/htmlsingle/#howto.traditional-deployment>

Spring Boot hỗ trợ triển khai truyền thống cũng như các hình thức triển khai hiện đại hơn. Phần này trả lời các câu hỏi thường gặp về triển khai truyền thống.
