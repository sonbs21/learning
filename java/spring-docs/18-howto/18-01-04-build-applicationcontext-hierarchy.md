# 18.1.4. Xây dựng phân cấp ApplicationContext (thêm context cha hoặc gốc) (Build an ApplicationContext Hierarchy (Adding a Parent or Root Context))

> Nguồn: <https://docs.spring.io/spring-boot/docs/3.2.5/reference/htmlsingle/#howto.application.context-hierarchy>

Bạn có thể dùng class `ApplicationBuilder` để tạo các phân cấp `ApplicationContext` cha/con. Xem "[Fluent Builder API](https://docs.spring.io/spring-boot/docs/3.2.5/reference/htmlsingle/#features.spring-application.fluent-builder-api)" trong phần 'Các tính năng của Spring Boot' để biết thêm thông tin.
