# 18.4.7. Tắt cấu hình MVC mặc định (Switch off the Default MVC Configuration)

> Nguồn: <https://docs.spring.io/spring-boot/docs/3.2.5/reference/htmlsingle/#howto.spring-mvc.switch-off-default-configuration>

Cách dễ nhất để kiểm soát hoàn toàn cấu hình MVC là cung cấp `@Configuration` của riêng bạn với annotation `@EnableWebMvc`. Làm vậy sẽ để toàn bộ cấu hình MVC trong tay bạn.
