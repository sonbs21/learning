# 18.4. Spring MVC

> Nguồn: <https://docs.spring.io/spring-boot/docs/3.2.5/reference/htmlsingle/#howto.spring-mvc>

Spring Boot có một số starter bao gồm Spring MVC. Lưu ý rằng một số starter bao gồm một dependency vào Spring MVC thay vì bao gồm trực tiếp nó. Phần này trả lời các câu hỏi thường gặp về Spring MVC và Spring Boot.
