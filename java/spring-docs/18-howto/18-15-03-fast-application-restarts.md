# 18.15.3. Khởi động lại ứng dụng nhanh (Fast Application Restarts)

> Nguồn: <https://docs.spring.io/spring-boot/docs/3.2.5/reference/htmlsingle/#howto.hotswapping.fast-application-restarts>

Module `spring-boot-devtools` bao gồm hỗ trợ khởi động lại ứng dụng tự động. Mặc dù không nhanh bằng các công nghệ như [JRebel](https://www.jrebel.com/products/jrebel), nó thường nhanh hơn đáng kể so với một lần "khởi động nguội" (cold start). Có lẽ bạn nên thử nó trước khi tìm hiểu một số tùy chọn reload phức tạp hơn được thảo luận ở phần sau của tài liệu này.

Để biết thêm chi tiết, xem phần [Developer Tools](https://docs.spring.io/spring-boot/docs/3.2.5/reference/htmlsingle/#using.devtools).
