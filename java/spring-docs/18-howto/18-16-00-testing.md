# 18.16. Kiểm thử (Testing)

> Nguồn: <https://docs.spring.io/spring-boot/docs/3.2.5/reference/htmlsingle/#howto.testing>

Spring Boot bao gồm một số tiện ích kiểm thử và các class hỗ trợ cũng như một starter chuyên dụng cung cấp các dependency kiểm thử thông dụng. Phần này trả lời các câu hỏi thường gặp về kiểm thử.
