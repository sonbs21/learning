# 18.1.5. Tạo ứng dụng không phải web (Create a Non-web Application)

> Nguồn: <https://docs.spring.io/spring-boot/docs/3.2.5/reference/htmlsingle/#howto.application.non-web-application>

Không phải mọi ứng dụng Spring đều phải là ứng dụng web (hoặc web service). Nếu bạn muốn thực thi một số code trong một phương thức `main` nhưng cũng muốn khởi động (bootstrap) một ứng dụng Spring để thiết lập hạ tầng sử dụng, bạn có thể dùng các tính năng `SpringApplication` của Spring Boot. Một `SpringApplication` thay đổi class `ApplicationContext` của nó, tùy thuộc vào việc nó cho rằng cần một ứng dụng web hay không. Điều đầu tiên bạn có thể làm để giúp nó là để các dependency liên quan đến server (chẳng hạn như servlet API) ra khỏi classpath. Nếu không thể làm vậy (ví dụ, bạn chạy hai ứng dụng từ cùng một code base) thì bạn có thể gọi tường minh `setWebApplicationType(WebApplicationType.NONE)` trên instance `SpringApplication` của mình hoặc đặt property `applicationContextClass` (thông qua Java API hoặc bằng các property bên ngoài). Code ứng dụng mà bạn muốn chạy làm business logic có thể được hiện thực dưới dạng một `CommandLineRunner` và đưa vào context dưới dạng một định nghĩa `@Bean`.
