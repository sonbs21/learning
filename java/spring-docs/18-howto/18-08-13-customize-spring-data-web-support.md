# 18.8.13. Tùy chỉnh hỗ trợ web của Spring Data (Customize Spring Data's Web Support)

> Nguồn: <https://docs.spring.io/spring-boot/docs/3.2.5/reference/htmlsingle/#howto.data-access.customize-spring-data-web-support>

Spring Data cung cấp hỗ trợ web giúp đơn giản hóa việc dùng các Spring Data repository trong một ứng dụng web. Spring Boot cung cấp các property trong namespace `spring.data.web` để tùy chỉnh cấu hình của nó. Lưu ý rằng nếu bạn đang dùng Spring Data REST, bạn phải dùng các property trong namespace `spring.data.rest` thay thế.
