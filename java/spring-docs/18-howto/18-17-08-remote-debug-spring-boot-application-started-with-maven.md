# 18.17.8. Debug từ xa một ứng dụng Spring Boot được khởi động bằng Maven (Remote Debug a Spring Boot Application Started with Maven)

> Nguồn: <https://docs.spring.io/spring-boot/docs/3.2.5/reference/htmlsingle/#howto.build.remote-debug-maven>

Để gắn một remote debugger vào một ứng dụng Spring Boot được khởi động bằng Maven, bạn có thể dùng property `jvmArguments` của [maven plugin](https://docs.spring.io/spring-boot/docs/3.2.5/maven-plugin/reference/htmlsingle/).

Xem [ví dụ này](https://docs.spring.io/spring-boot/docs/3.2.5/maven-plugin/reference/htmlsingle/#run-example-debug) để biết thêm chi tiết.
