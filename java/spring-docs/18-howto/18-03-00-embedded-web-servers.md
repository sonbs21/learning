# 18.3. Embedded web server (Embedded Web Servers)

> Nguồn: <https://docs.spring.io/spring-boot/docs/3.2.5/reference/htmlsingle/#howto.webserver>

Mỗi ứng dụng web Spring Boot đều bao gồm một embedded web server. Tính năng này dẫn đến một số câu hỏi how-to, bao gồm cách thay đổi embedded server và cách cấu hình embedded server. Phần này trả lời những câu hỏi đó.
