# 18.12.5. Lưu trữ Job repository (Storing the Job Repository)

> Nguồn: <https://docs.spring.io/spring-boot/docs/3.2.5/reference/htmlsingle/#howto.batch.storing-job-repository>

Spring Batch cần một kho dữ liệu cho `Job` repository. Nếu bạn dùng Spring Boot, bạn phải dùng một cơ sở dữ liệu thực sự. Lưu ý rằng nó có thể là một in-memory database, xem [Cấu hình Job Repository (Configuring a Job Repository)](https://docs.spring.io/spring-batch/reference/5.1/job.html#configuringJobRepository).
