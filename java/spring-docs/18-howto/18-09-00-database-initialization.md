# 18.9. Khởi tạo cơ sở dữ liệu (Database Initialization)

> Nguồn: <https://docs.spring.io/spring-boot/docs/3.2.5/reference/htmlsingle/#howto.data-initialization>

Một cơ sở dữ liệu SQL có thể được khởi tạo theo nhiều cách khác nhau tùy thuộc vào stack của bạn. Tất nhiên, bạn cũng có thể làm thủ công, miễn là cơ sở dữ liệu là một process riêng biệt. Khuyến nghị dùng một cơ chế duy nhất cho việc sinh schema.
