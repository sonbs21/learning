# 17.5. Đọc gì tiếp theo (What to Read Next)

> Nguồn: <https://docs.spring.io/spring-boot/docs/3.2.5/reference/htmlsingle/#build-tool-plugins.whats-next>

Nếu bạn quan tâm đến cách các plugin công cụ build hoạt động, bạn có thể xem module [`spring-boot-tools`](https://github.com/spring-projects/spring-boot/tree/v3.2.5/spring-boot-project/spring-boot-tools) trên GitHub. Thêm chi tiết kỹ thuật về định dạng jar thực thi được đề cập trong [phụ lục](https://docs.spring.io/spring-boot/docs/3.2.5/reference/htmlsingle/#appendix.executable-jar).

Nếu bạn có các câu hỏi cụ thể liên quan đến build, hãy xem các hướng dẫn "[how-to](https://docs.spring.io/spring-boot/docs/3.2.5/reference/htmlsingle/#howto)".
