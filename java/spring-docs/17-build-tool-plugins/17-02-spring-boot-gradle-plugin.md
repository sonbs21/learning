# 17.2. Spring Boot Gradle Plugin

> Nguồn: <https://docs.spring.io/spring-boot/docs/3.2.5/reference/htmlsingle/#build-tool-plugins.gradle>

Spring Boot Gradle Plugin cung cấp hỗ trợ Spring Boot trong Gradle, cho phép bạn đóng gói các file nén jar hoặc war thực thi, chạy ứng dụng Spring Boot, và dùng tính năng quản lý dependency do `spring-boot-dependencies` cung cấp. Nó yêu cầu Gradle 7.x (7.5 trở lên) hoặc 8.x. Xem tài liệu của plugin để tìm hiểu thêm:

- Tài liệu tham khảo ([HTML](https://docs.spring.io/spring-boot/docs/3.2.5/gradle-plugin/reference/htmlsingle/) và [PDF](https://docs.spring.io/spring-boot/docs/3.2.5/gradle-plugin/reference/pdf/spring-boot-gradle-plugin-reference.pdf))
- [API](https://docs.spring.io/spring-boot/docs/3.2.5/gradle-plugin/api/)
