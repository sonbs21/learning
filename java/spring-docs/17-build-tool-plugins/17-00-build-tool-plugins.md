# 17. Các plugin công cụ build (Build Tool Plugins)

> Nguồn: <https://docs.spring.io/spring-boot/docs/3.2.5/reference/htmlsingle/#build-tool-plugins>

Spring Boot cung cấp các plugin công cụ build cho Maven và Gradle. Các plugin cung cấp nhiều tính năng khác nhau, bao gồm việc đóng gói các jar thực thi. Phần này cung cấp thêm chi tiết về cả hai plugin cũng như một số trợ giúp nếu bạn cần mở rộng một hệ thống build không được hỗ trợ. Nếu bạn mới bắt đầu, có lẽ bạn nên đọc "[Hệ thống build (Build Systems)](https://docs.spring.io/spring-boot/docs/3.2.5/reference/htmlsingle/#using.build-systems)" trong phần "[Phát triển với Spring Boot (Developing with Spring Boot)](https://docs.spring.io/spring-boot/docs/3.2.5/reference/htmlsingle/#using)" trước.
