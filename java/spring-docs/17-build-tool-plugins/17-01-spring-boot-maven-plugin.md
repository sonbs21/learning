# 17.1. Spring Boot Maven Plugin

> Nguồn: <https://docs.spring.io/spring-boot/docs/3.2.5/reference/htmlsingle/#build-tool-plugins.maven>

Spring Boot Maven Plugin cung cấp hỗ trợ Spring Boot trong Maven, cho phép bạn đóng gói các file nén jar hoặc war thực thi và chạy một ứng dụng "tại chỗ" ("in-place"). Để dùng nó, bạn phải dùng Maven 3.6.3 trở lên.

Xem tài liệu của plugin để tìm hiểu thêm:

- Tài liệu tham khảo ([HTML](https://docs.spring.io/spring-boot/docs/3.2.5/maven-plugin/reference/htmlsingle/) và [PDF](https://docs.spring.io/spring-boot/docs/3.2.5/maven-plugin/reference/pdf/spring-boot-maven-plugin-reference.pdf))
- [API](https://docs.spring.io/spring-boot/docs/3.2.5/maven-plugin/api/)
