# 5.1. Nâng cấp từ 1.x (Upgrading From 1.x)

> Nguồn: <https://docs.spring.io/spring-boot/docs/3.2.5/reference/htmlsingle/#upgrading.from-1x>

Nếu bạn đang nâng cấp từ bản phát hành `1.x` của Spring Boot, hãy xem ["hướng dẫn chuyển đổi" (migration guide) trên wiki của dự án](https://github.com/spring-projects/spring-boot/wiki/Spring-Boot-2.0-Migration-Guide), nơi cung cấp hướng dẫn nâng cấp chi tiết. Hãy xem thêm ["release notes"](https://github.com/spring-projects/spring-boot/wiki) để có danh sách các tính năng "mới và đáng chú ý" ("new and noteworthy") của từng bản phát hành.
