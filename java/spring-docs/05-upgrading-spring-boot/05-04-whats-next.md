# 5.4. Đọc gì tiếp theo (What to Read Next)

> Nguồn: <https://docs.spring.io/spring-boot/docs/3.2.5/reference/htmlsingle/#upgrading.whats-next>

Khi bạn đã quyết định nâng cấp ứng dụng, bạn có thể tìm thông tin chi tiết về các tính năng cụ thể trong phần còn lại của tài liệu.

Tài liệu của Spring Boot là dành riêng cho từng phiên bản, vì vậy mọi thông tin bạn tìm thấy ở đây sẽ chứa những thay đổi cập nhật nhất có trong phiên bản đó.
