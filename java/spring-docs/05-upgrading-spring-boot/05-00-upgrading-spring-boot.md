# 5. Nâng cấp Spring Boot (Upgrading Spring Boot)

> Nguồn: <https://docs.spring.io/spring-boot/docs/3.2.5/reference/htmlsingle/#upgrading>

Hướng dẫn cách nâng cấp từ các phiên bản Spring Boot cũ hơn được cung cấp trên [wiki](https://github.com/spring-projects/spring-boot/wiki) của dự án. Hãy theo các link trong phần [release notes](https://github.com/spring-projects/spring-boot/wiki#release-notes) để tìm phiên bản mà bạn muốn nâng cấp lên.

Hướng dẫn nâng cấp luôn là mục đầu tiên trong release notes. Nếu bạn đang chậm hơn một bản phát hành trở lên, hãy đảm bảo rằng bạn cũng xem lại release notes của các phiên bản mà bạn đã nhảy qua.
