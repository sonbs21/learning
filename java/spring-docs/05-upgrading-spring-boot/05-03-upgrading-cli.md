# 5.3. Nâng cấp Spring Boot CLI (Upgrading the Spring Boot CLI)

> Nguồn: <https://docs.spring.io/spring-boot/docs/3.2.5/reference/htmlsingle/#upgrading.cli>

Để nâng cấp một bản cài đặt CLI hiện có, hãy dùng lệnh phù hợp của trình quản lý gói (package manager) (ví dụ: `brew upgrade`). Nếu bạn đã cài đặt CLI thủ công, hãy làm theo [hướng dẫn tiêu chuẩn](https://docs.spring.io/spring-boot/docs/3.2.5/reference/htmlsingle/#getting-started.installing.cli.manual-installation), và nhớ cập nhật biến môi trường `PATH` để xóa mọi tham chiếu tới phiên bản cũ.
