# 16.1. Cài đặt CLI (Installing the CLI)

> Nguồn: <https://docs.spring.io/spring-boot/docs/3.2.5/reference/htmlsingle/#cli.installation>

Spring Boot CLI (Command-Line Interface - giao diện dòng lệnh) có thể được cài đặt thủ công, bằng SDKMAN! (SDK Manager), hoặc bằng Homebrew hay MacPorts nếu bạn là người dùng OSX. Xem *[Cài đặt Spring Boot CLI (Installing the Spring Boot CLI)](https://docs.spring.io/spring-boot/docs/3.2.5/reference/htmlsingle/#getting-started.installing.cli)* trong phần "Bắt đầu" để có hướng dẫn cài đặt đầy đủ.
