# 6.10. Đọc gì tiếp theo (What to Read Next)

> Nguồn: <https://docs.spring.io/spring-boot/docs/3.2.5/reference/htmlsingle/#using.whats-next>

Giờ đây bạn đã hiểu cách sử dụng Spring Boot và một số best practice nên tuân theo. Bây giờ bạn có thể tiếp tục tìm hiểu sâu về các *[tính năng cụ thể của Spring Boot (Spring Boot features)](https://docs.spring.io/spring-boot/docs/3.2.5/reference/htmlsingle/#features)*, hoặc bạn có thể nhảy trước và đọc về các khía cạnh "[sẵn sàng cho production (production ready)](https://docs.spring.io/spring-boot/docs/3.2.5/reference/htmlsingle/#actuator)" của Spring Boot.
