# 15. Hỗ trợ GraalVM Native Image (GraalVM Native Image Support)

> Nguồn: <https://docs.spring.io/spring-boot/docs/3.2.5/reference/htmlsingle/#native-image>

[GraalVM Native Image](https://www.graalvm.org/native-image/) là các file thực thi độc lập có thể được tạo ra bằng cách xử lý trước (ahead-of-time) các ứng dụng Java đã biên dịch. Native Image thường có dung lượng bộ nhớ sử dụng nhỏ hơn và khởi động nhanh hơn so với các phiên bản chạy trên JVM.
