# 15.5. Đọc gì tiếp theo (What to Read Next)

> Nguồn: <https://docs.spring.io/spring-boot/docs/3.2.5/reference/htmlsingle/#native-image.whats-next>

Nếu bạn muốn tìm hiểu thêm về xử lý ahead-of-time do các build plugin của chúng tôi cung cấp, hãy xem tài liệu plugin [Maven](https://docs.spring.io/spring-boot/docs/3.2.5/maven-plugin/reference/htmlsingle/) và [Gradle](https://docs.spring.io/spring-boot/docs/3.2.5/gradle-plugin/reference/htmlsingle/). Để tìm hiểu thêm về các API được dùng để thực hiện việc xử lý, hãy duyệt các package `org.springframework.aot.generate` và `org.springframework.beans.factory.aot` trong mã nguồn Spring Framework.

Về các hạn chế đã biết với Spring và GraalVM, vui lòng xem [wiki của Spring Boot](https://github.com/spring-projects/spring-boot/wiki/Spring-Boot-with-GraalVM).

Phần tiếp theo đề cập đến *[Spring Boot CLI](https://docs.spring.io/spring-boot/docs/3.2.5/reference/htmlsingle/#cli)*.
