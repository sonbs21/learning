# 14. Triển khai ứng dụng Spring Boot (Deploying Spring Boot Applications)

> Nguồn: <https://docs.spring.io/spring-boot/docs/3.2.5/reference/htmlsingle/#deployment>

Các tùy chọn đóng gói linh hoạt của Spring Boot cung cấp rất nhiều lựa chọn khi triển khai ứng dụng. Bạn có thể triển khai ứng dụng Spring Boot lên nhiều nền tảng cloud khác nhau, lên máy ảo/máy thật, hoặc làm cho chúng có thể thực thi đầy đủ (fully executable) trên các hệ thống Unix.

Phần này đề cập đến một số tình huống triển khai phổ biến hơn.
