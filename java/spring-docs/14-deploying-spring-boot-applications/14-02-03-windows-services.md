# 14.2.3. Service Microsoft Windows (Microsoft Windows Services)

> Nguồn: <https://docs.spring.io/spring-boot/docs/3.2.5/reference/htmlsingle/#deployment.installing.windows-services>

Một ứng dụng Spring Boot có thể được khởi động như một service Windows bằng [`winsw`](https://github.com/kohsuke/winsw).

Một ([ví dụ được duy trì riêng](https://github.com/snicoll/spring-boot-daemon)) mô tả từng bước cách bạn có thể tạo một service Windows cho ứng dụng Spring Boot của mình.
