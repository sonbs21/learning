# 14.2. Cài đặt ứng dụng Spring Boot (Installing Spring Boot Applications)

> Nguồn: <https://docs.spring.io/spring-boot/docs/3.2.5/reference/htmlsingle/#deployment.installing>

Ngoài việc chạy trực tiếp ứng dụng Spring Boot bằng `java -jar`, cũng có thể chạy chúng dưới dạng service `systemd`, `init.d` hoặc Windows.
