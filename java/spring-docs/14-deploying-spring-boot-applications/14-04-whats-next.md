# 14.4. Đọc gì tiếp theo (What to Read Next)

> Nguồn: <https://docs.spring.io/spring-boot/docs/3.2.5/reference/htmlsingle/#deployment.whats-next>

Xem các trang web [Cloud Foundry](https://www.cloudfoundry.org/), [Heroku](https://www.heroku.com/), [OpenShift](https://www.openshift.com), và [Boxfuse](https://boxfuse.com) để biết thêm thông tin về các loại tính năng mà một PaaS có thể cung cấp. Đây chỉ là bốn trong số các nhà cung cấp PaaS Java phổ biến nhất. Vì Spring Boot rất phù hợp với việc triển khai trên cloud, bạn cũng có thể thoải mái cân nhắc các nhà cung cấp khác.

Phần tiếp theo đề cập đến *[GraalVM Native Image](https://docs.spring.io/spring-boot/docs/3.2.5/reference/htmlsingle/#native-image)*, hoặc bạn có thể nhảy tới để đọc về *[Spring Boot CLI](https://docs.spring.io/spring-boot/docs/3.2.5/reference/htmlsingle/#cli)* hoặc *[các plugin công cụ build](https://docs.spring.io/spring-boot/docs/3.2.5/reference/htmlsingle/#build-tool-plugins)* của chúng tôi.
