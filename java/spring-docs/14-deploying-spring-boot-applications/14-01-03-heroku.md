# 14.1.3. Heroku

> Nguồn: <https://docs.spring.io/spring-boot/docs/3.2.5/reference/htmlsingle/#deployment.cloud.heroku>

Heroku là một nền tảng PaaS phổ biến khác. Để tùy chỉnh các bản build Heroku, bạn cung cấp một `Procfile`, cung cấp câu lệnh cần thiết để triển khai một ứng dụng. Heroku gán một `port` cho ứng dụng Java sử dụng, rồi đảm bảo việc định tuyến tới URI bên ngoài hoạt động.

Bạn phải cấu hình ứng dụng để lắng nghe trên đúng cổng. Ví dụ sau cho thấy `Procfile` cho ứng dụng REST khởi đầu của chúng ta:

```
web: java -Dserver.port=$PORT -jar target/demo-0.0.1-SNAPSHOT.jar
```

Spring Boot làm cho các tham số `-D` khả dụng dưới dạng property có thể truy cập từ một instance `Environment` của Spring. Configuration property `server.port` được đưa vào instance Tomcat, Jetty, hoặc Undertow nhúng, sau đó instance này dùng cổng khi khởi động. Biến môi trường `$PORT` được nền tảng PaaS Heroku gán cho chúng ta.

Đây sẽ là mọi thứ bạn cần. Quy trình triển khai phổ biến nhất cho các triển khai Heroku là `git push` code lên production, như trong ví dụ sau:

```shell
$ git push heroku main
```
