# 8. Web

> Nguồn: <https://docs.spring.io/spring-boot/docs/3.2.5/reference/htmlsingle/#web>

Spring Boot rất phù hợp cho việc phát triển ứng dụng web. Bạn có thể tạo một HTTP server khép kín (self-contained) bằng cách dùng Tomcat, Jetty, Undertow, hoặc Netty nhúng. Hầu hết các ứng dụng web dùng module `spring-boot-starter-web` để nhanh chóng khởi chạy. Bạn cũng có thể chọn xây dựng ứng dụng web reactive bằng module `spring-boot-starter-webflux`.

Nếu bạn chưa từng phát triển ứng dụng web Spring Boot, bạn có thể làm theo ví dụ "Hello World!" trong phần *[Bắt đầu (Getting started)](https://docs.spring.io/spring-boot/docs/3.2.5/reference/htmlsingle/#getting-started.first-application)*.
