# 8.8. Đọc gì tiếp theo (What to Read Next)

> Nguồn: <https://docs.spring.io/spring-boot/docs/3.2.5/reference/htmlsingle/#web.whats-next>

Giờ đây bạn đã có hiểu biết tốt về cách phát triển ứng dụng web với Spring Boot. Các phần tiếp theo mô tả cách Spring Boot tích hợp với nhiều [công nghệ dữ liệu](https://docs.spring.io/spring-boot/docs/3.2.5/reference/htmlsingle/#data), [hệ thống messaging](https://docs.spring.io/spring-boot/docs/3.2.5/reference/htmlsingle/#messaging), và các khả năng IO khác. Bạn có thể chọn bất kỳ phần nào dựa trên nhu cầu của ứng dụng.
