# 12. Container Image (Container Images)

> Nguồn: <https://docs.spring.io/spring-boot/docs/3.2.5/reference/htmlsingle/#container-images>

Các ứng dụng Spring Boot có thể được container hóa [bằng Dockerfile](https://docs.spring.io/spring-boot/docs/3.2.5/reference/htmlsingle/#container-images.dockerfiles), hoặc [bằng Cloud Native Buildpacks để tạo các container image tương thích docker, được tối ưu, có thể chạy ở bất kỳ đâu](https://docs.spring.io/spring-boot/docs/3.2.5/reference/htmlsingle/#container-images.buildpacks).
