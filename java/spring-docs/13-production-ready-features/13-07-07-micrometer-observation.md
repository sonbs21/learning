# 13.7.7. Tích hợp với Micrometer Observation (Integration with Micrometer Observation)

> Nguồn: <https://docs.spring.io/spring-boot/docs/3.2.5/reference/htmlsingle/#actuator.metrics.micrometer-observation>

Một `DefaultMeterObservationHandler` được tự động đăng ký trên `ObservationRegistry`, tạo ra metric cho mọi observation đã hoàn tất.
