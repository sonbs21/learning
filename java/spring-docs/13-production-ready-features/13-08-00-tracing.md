# 13.8. Tracing

> Nguồn: <https://docs.spring.io/spring-boot/docs/3.2.5/reference/htmlsingle/#actuator.micrometer-tracing>

Spring Boot Actuator cung cấp quản lý dependency và auto-configuration cho [Micrometer Tracing](https://micrometer.io/docs/tracing), một facade cho các thư viện tracer phổ biến.

> **MẸO (TIP):** Để tìm hiểu thêm về các khả năng của Micrometer Tracing, hãy xem [tài liệu tham khảo](https://micrometer.io/docs/tracing) của nó.
