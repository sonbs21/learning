# 13.8.9. Kiểm thử (Tests)

> Nguồn: <https://docs.spring.io/spring-boot/docs/3.2.5/reference/htmlsingle/#actuator.micrometer-tracing.tests>

Các component tracing có báo cáo dữ liệu không được tự động cấu hình khi dùng `@SpringBootTest`. Xem [phần kiểm thử](https://docs.spring.io/spring-boot/docs/3.2.5/reference/htmlsingle/#features.testing.spring-boot-applications.tracing) để biết thêm chi tiết.
