# 13.10.1. Ghi lại trao đổi HTTP tùy chỉnh (Custom HTTP Exchange Recording)

> Nguồn: <https://docs.spring.io/spring-boot/docs/3.2.5/reference/htmlsingle/#actuator.http-exchanges.custom>

Để tùy chỉnh các mục được đưa vào mỗi lần trao đổi được ghi lại, hãy dùng configuration property `management.httpexchanges.recording.include`.

Để tắt hoàn toàn việc ghi lại, hãy đặt `management.httpexchanges.recording.enabled` thành `false`.
