# 13.8.1. Các tracer được hỗ trợ (Supported Tracers)

> Nguồn: <https://docs.spring.io/spring-boot/docs/3.2.5/reference/htmlsingle/#actuator.micrometer-tracing.tracers>

Spring Boot đi kèm auto-configuration cho các tracer sau:

- [OpenTelemetry](https://opentelemetry.io/) với [Zipkin](https://zipkin.io/), [Wavefront](https://docs.wavefront.com/), hoặc [OTLP](https://opentelemetry.io/docs/reference/specification/protocol/)
- [OpenZipkin Brave](https://github.com/openzipkin/brave) với [Zipkin](https://zipkin.io/) hoặc [Wavefront](https://docs.wavefront.com/)
