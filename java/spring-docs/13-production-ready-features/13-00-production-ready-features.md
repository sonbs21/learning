# 13. Các tính năng sẵn sàng cho production (Production-ready Features)

> Nguồn: <https://docs.spring.io/spring-boot/docs/3.2.5/reference/htmlsingle/#actuator>

Spring Boot bao gồm một số tính năng bổ sung để giúp bạn giám sát và quản lý ứng dụng khi đưa nó lên production. Bạn có thể chọn quản lý và giám sát ứng dụng bằng các HTTP endpoint hoặc bằng JMX. Việc thu thập auditing, health, và metrics cũng có thể được tự động áp dụng cho ứng dụng của bạn.
