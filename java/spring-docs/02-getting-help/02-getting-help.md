# 2. Nhận trợ giúp (Getting Help)

> Nguồn: <https://docs.spring.io/spring-boot/docs/3.2.5/reference/htmlsingle/#getting-help>

Nếu bạn gặp khó khăn với Spring Boot, chúng tôi rất sẵn lòng giúp đỡ.

- Hãy thử các [tài liệu How-to](https://docs.spring.io/spring-boot/docs/3.2.5/reference/htmlsingle/#howto). Chúng cung cấp giải pháp cho những câu hỏi phổ biến nhất.
- Học những kiến thức cơ bản về Spring. Spring Boot được xây dựng dựa trên nhiều dự án Spring khác. Hãy xem trang web [spring.io](https://spring.io) để có kho tài liệu tham khảo phong phú. Nếu bạn mới bắt đầu với Spring, hãy thử một trong các [hướng dẫn (guides)](https://spring.io/guides).
- Đặt câu hỏi. Chúng tôi theo dõi [stackoverflow.com](https://stackoverflow.com) cho các câu hỏi được gắn thẻ `spring-boot`.
- Báo cáo lỗi (bug) của Spring Boot tại [github.com/spring-projects/spring-boot/issues](https://github.com/spring-projects/spring-boot/issues).

> **Lưu ý:** Toàn bộ Spring Boot đều là mã nguồn mở, kể cả tài liệu. Nếu bạn phát hiện vấn đề trong tài liệu hoặc muốn cải thiện chúng, hãy [tham gia đóng góp](https://github.com/spring-projects/spring-boot/tree/v3.2.5).
