# Đánh index/Tìm kiếm JSON document (Index/Search JSON documents)

> Nguồn: <https://redis.io/docs/latest/develop/data-types/json/indexing_json/>

Ngoài việc lưu trữ các JSON document, bạn cũng có thể đánh index chúng bằng tính năng [Redis Search](https://redis.io/docs/latest/develop/ai/search-and-query). Điều này cho phép tìm kiếm toàn văn (full-text search) và truy xuất document dựa trên nội dung của chúng.

Để dùng các tính năng này, hãy cài đặt [Redis Open Source](https://redis.io/docs/latest/operate/oss_and_stack).

Xem [tutorial](https://redis.io/docs/latest/develop/ai/search-and-query/indexing) để học cách tìm kiếm và truy vấn JSON của bạn.
