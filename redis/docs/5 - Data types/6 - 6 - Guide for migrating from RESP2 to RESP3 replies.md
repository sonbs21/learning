# Hướng dẫn chuyển từ phản hồi RESP2 sang RESP3 (Guide for migrating from RESP2 to RESP3 replies)

> Nguồn: <https://redis.io/docs/latest/develop/data-types/json/resp3/>

Trong RESP3, giá trị mặc định của đối số path tùy chọn đã được đổi từ `.` thành `$`.
Do thay đổi này, phản hồi (reply) của một số lệnh đã thay đổi đôi chút.
Trang này đưa ra một so sánh ngắn gọn giữa phản hồi RESP2 và RESP3 cho các lệnh JSON để giúp developer chuyển client của họ từ RESP2 sang RESP3.

### So sánh phản hồi của các lệnh JSON (JSON command replies comparison)

Các kiểu được mô tả bằng [cú pháp "giống TypeScript" ("TypeScript-like" syntax)](https://www.typescriptlang.org/docs/handbook/2/everyday-types.html). `Array<a>` biểu thị một [mảng](https://www.typescriptlang.org/docs/handbook/2/everyday-types.html#arrays) mà kiểu của các phần tử đã biết, nhưng số lượng phần tử thì không.

| Lệnh                                                                                                                                                    | RESP2                                                                                                                                                                                            | RESP3                                                                                                                                                                                                               |
|---------------------------------------------------------------------------------------------------------------------------------------------------------|--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Tất cả các lệnh JSON                                                                                                                                       | **Giá trị mặc định của đối số `path` tùy chọn**: `.`                                                                                                                                               | **Giá trị mặc định của đối số `path` tùy chọn:** `$`                                                                                                                                                                  |
| JSON.ARRAPPEND<br/>JSON.ARRINDEX<br/>JSON.ARRINSERT<br/>JSON.ARRLEN<br/>JSON.ARRTRIM<br/>JSON.OBJLEN<br/>JSON.STRAPPEND<br/>JSON.STRLEN<br/>JSON.TOGGLE | *Đối số path dựa trên `$`:* <br/> Phản hồi: Array\<BulkString &#124; null> <br/><br/> *Đối số path dựa trên `.`:*&nbsp;<br/> Phản hồi: BulkString                                                       | *Đối số path dựa trên `$`:*&nbsp; <br/> Phản hồi: Array\<number &#124; null> <br/><br/> *Đối số path dựa trên `.`:* <br/> Phản hồi: number                                                                                 |
| JSON.GET                                                                                                                                                | Phản hồi: chuỗi được mã hóa JSON  <br/> Ví dụ: <br/> ```> JSON.SET k $ "[1,2,3]"```<br/> ```> JSON.GET k```<br/>```"[1,2,3]"```                                                                      | Phản hồi: chuỗi được mã hóa JSON với một mảng cấp cao nhất  <br/> Ví dụ: <br/> ```> JSON.SET k $ "[1,2,3]"```<br/> ```> JSON.GET k```<br/>```"[[1,2,3]]"```                                                                |
| JSON.NUMINCRBY<br/>JSON.NUMMULTBY                                                                                                                       | *Đối số path dựa trên `$`:* <br/> Phản hồi: BulkString được mã hóa JSON &#124; null <br/><br/> *Đối số path dựa trên `.`:*&nbsp;<br/> Phản hồi: BulkString &#124; null &#124; error                         | *Đối số path dựa trên `$`:* <br/> Phản hồi: Array\<number &#124;  null> &#124; error <br/><br/> *Đối số path dựa trên `.`:*&nbsp;<br/> Phản hồi: number &#124;  null &#124; error                                          |
| JSON.OBJKEYS                                                                                                                                            | *Đối số path dựa trên `$`:* <br/> Phản hồi: Array\<Array\<BulkString\>> <br/><br/> *Đối số path dựa trên `.`:*&nbsp;<br/> Phản hồi: Array\<BulkString>                                                  | *Đối số path dựa trên `$`:* <br/> Phản hồi: Array\<Array\<BulkString\>> <br/><br/> *Đối số path dựa trên `.`:*&nbsp;<br/> Phản hồi: Array\<BulkString>                                                                     |
| JSON.TYPE                                                                                                                                               | *Đối số path dựa trên `$`:* <br/> Phản hồi: Array\<BulkString\> <br/> Ví dụ: <br />```> JSON.TYPE k $```<br />```1) "array"``` <br/><br/> *Đối số path dựa trên `.`:*&nbsp;<br/> Phản hồi: BulkString | *Đối số path dựa trên `$`:* <br/> Phản hồi: Array\<Array\<BulkString\>> <br/> Ví dụ: <br />```> JSON.TYPE k $```<br />```1) 1) "array"``` <br/><br/> *Đối số path dựa trên `.`:*&nbsp;<br/> Phản hồi: Array\<BulkString> |
