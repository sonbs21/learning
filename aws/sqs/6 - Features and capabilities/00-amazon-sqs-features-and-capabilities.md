# Các tính năng và khả năng của Amazon SQS (Amazon SQS features and capabilities)

> Nguồn: [Amazon SQS features and capabilities](https://docs.aws.amazon.com/AWSSimpleQueueService/latest/SQSDeveloperGuide/features-capabilities.html)

Chủ đề này cung cấp các tính năng thường được sử dụng trong Amazon SQS để quản lý message queue, tối ưu hóa hiệu năng, đảm bảo việc phân phối message tin cậy, và xử lý message một cách hiệu quả.
