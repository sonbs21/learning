# Xử lý lỗi và các message có vấn đề trong Amazon SQS (Amazon SQS error handling and problematic messages)

> Nguồn: [Amazon SQS error handling and problematic messages](https://docs.aws.amazon.com/AWSSimpleQueueService/latest/SQSDeveloperGuide/best-practices-error-handling.html)

Chủ đề này cung cấp các hướng dẫn chi tiết về việc quản lý và giảm thiểu lỗi trong Amazon SQS, bao gồm các kỹ thuật xử lý lỗi request (request error), thu nhận các message có vấn đề (problematic message), và cấu hình thời gian lưu giữ (retention) của dead-letter queue để đảm bảo độ tin cậy của message.

**Các chủ đề (Topics)**

- [Handling request errors in Amazon SQS](https://docs.aws.amazon.com/AWSSimpleQueueService/latest/SQSDeveloperGuide/handling-request-errors.html)
- [Capturing problematic messages in Amazon SQS](https://docs.aws.amazon.com/AWSSimpleQueueService/latest/SQSDeveloperGuide/capturing-problematic-messages.html)
- [Setting-up dead-letter queue retention in Amazon SQS](https://docs.aws.amazon.com/AWSSimpleQueueService/latest/SQSDeveloperGuide/setting-up-dead-letter-queue-retention.html)
