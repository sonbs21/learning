# Cấu hình Amazon SQS queue bằng Amazon SQS console (Configuring Amazon SQS queues using the Amazon SQS console)

> Nguồn: [Configuring Amazon SQS queues using the Amazon SQS console](https://docs.aws.amazon.com/AWSSimpleQueueService/latest/SQSDeveloperGuide/sqs-configuring.html)

Sử dụng Amazon SQS console để cấu hình và quản lý các Amazon SQS queue và các tính năng. Bạn cũng có thể:

- Bật mã hóa phía máy chủ (server-side encryption) để tăng cường bảo mật.
- Liên kết (associate) một dead-letter queue để xử lý các message chưa được xử lý.
- Thiết lập một trigger để gọi (invoke) một Lambda function cho việc xử lý hướng sự kiện (event-driven processing).
